# Portal Steren · TEFES

Portal de trabajo de las tiendas Steren en Ecuador (TEFES): página de cada tienda y panel de supervisores.

Se abre con el enlace que entrega la administración (`?t=` para tiendas, `?p=` para supervisores).
Estas páginas no guardan datos: los piden al servidor del portal, que valida cada enlace.

Las páginas se generan automáticamente desde el código del portal; no se editan a mano.

Versión publicada: igual a Apps Script @86 (25-oct-2026): temas arriba, buscador, color Steren y contactos de tiendas por ciudad.
